# E. Deniz Gedikli — personal webpage

This is a single-file academic profile page inspired by the layout of the example site. The HTML includes its own styling and small interactions, so no build tools are needed.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io`, using your exact GitHub username.
2. Add `index.html` to the repository root and commit it. You can also add this README if you want.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)` and save.
4. After GitHub finishes publishing, visit `https://YOUR-USERNAME.github.io`.

## Before publishing

- Check the wording, course list, office details, selected publications, and external links.
- The profile photo currently loads from the UH Mānoa faculty page. To use another image, add it to the repository and change the `src` on the portrait `<img>` in `index.html` to that image's path.
- The page footer says “All rights reserved.” The repository has no software license. A public GitHub repository can still be viewed and forked through GitHub; that does not grant general permission to reuse the site's content.

To update the site later, edit `index.html` and commit the change.
